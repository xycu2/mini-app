# 🤖 Telegram Mini App on React

My academic project,which I made about a year ago using a video tutorial. This is a web application (Mini App), which opens and works right away inside the Telegram messenger.
With the help of this project я впервые прикоснулся к библиотеке React, сборщику Vite и узнал, как устроены мини-приложения в ТГ. 

### 🛠️ Стек технологий:
* React.js
* Vite
* @telegram-apps/sdk (официальный пакет для интеграции с Telegram)
