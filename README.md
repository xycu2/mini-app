# 🤖 Telegram Mini App on React

My academic project, который я сделал около года назад по видеоуроку. Это веб-приложение (Mini App), которое открывается и работает прямо внутри мессенджера Telegram.

С помощью этого проекта я впервые прикоснулся к библиотеке React, сборщику Vite и узнал, как устроены мини-приложения в ТГ. 

### 🛠️ Стек технологий:
* React.js
* Vite
* @telegram-apps/sdk (официальный пакет для интеграции с Telegram)
